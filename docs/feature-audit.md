# 功能核查：v4.3 承诺的功能，v5.1 里哪些有、哪些没有

对照 v4.3 README/SKILL 列出的每一项学生可见功能，逐条标注在 v5.1 中的状态。
✅ 已实现（并在 EEC 160 / MIT 6.006 / Yale PSYC 110 三套真实资料上实测）；🔶 部分实现或换了形式；❌ 未实现（及原因）。

## 教学

| v4.3 功能 | v5.1 状态 | 说明 |
|---|---|---|
| 按章节从资料讲课，只读当前章 | ✅ | `next` 按固定字数分段吐出当前章原文，带 `[文件 p.页码]`；不预载其他章 |
| 七步讲题（题面图→问什么→读图量→公式→演算→答案→溯源） | ✅ | 压缩为 SKILL §3 的 4 步 + §4 图片规则；顺序相同（先图、后讲、再溯源） |
| 有图题先看图，图未显示不出题 | ✅ | `quiz` 先列 🖼 题面图路径；SKILL §4 要求先把图放进对话再提问 |
| 从原讲义/材料裁剪图片放进对话 | ✅ **新增** | `setup` 自动检测讲义 PDF 里的矢量图/嵌入图并裁成 PNG（EEC 160：235 张）；题目/答案所在区域含图时裁出题面图/答案图（16 张）；PPTX/DOCX 嵌入图直接抽出；`figure <文件> <页> --crop` 可手动截任意区域 |
| 答案图只在讲解答案时出现 | ✅ | `quiz` 只给题面图；`check` 才给答案图 |
| 学生自己的作业扫描件不当作答案展示 | ✅ | 扫描/手写页自动识别并跳过（EEC 160：140 页），不进题库、不裁图 |
| 画图题先算后画（AVL 等） | ❌ | 未单独实现；属于模型行为，SKILL 未强调。可在 SKILL §3 加一句 |
| 零基础/补弱/查缺 3 种模式 × 4 档时间 | 🔶 | 改为 `--days N`（决定节奏）与 `--start N`（起点）；SKILL §3 按天数定节奏 |
| 知识点窗口（3–7 天回问是否记得） | ❌ | 删除。用 `mistakes` 与 `note --type confusion` 覆盖“回头复习”的目的 |
| 逐题精讲模式 step_by_step | 🔶 | 默认就是一段一段讲；`--slice` 调小即逐题 |

## 出题与判分

| v4.3 功能 | v5.1 状态 | 说明 |
|---|---|---|
| 只从资料题库出题，绝不自编冒充 | ✅ | `quiz` 只读 `quiz_bank.json`；无题时明确提示只能出 ⚠️ AI 题 |
| 六种题型（选择/主观/画图/填空/判断/代码） | 🔶 | 自动识别 choice / true_false / fill_blank / subjective；diagram 与 code 未单列（按主观题处理） |
| 题目与答案分册自动配对 | ✅ | `hw2 (4)(1).pdf` ↔ `homework2solutions.pdf`、`q1.pdf` ↔ `q1_sol.pdf`、`作业2.txt` ↔ `作业2答案.txt`；教材题号 `Problem 1.3.10` ↔ `Problem 1.3.10 Solution`（EEC 160：89/89 配对） |
| 主观题按 keywords 判分 | 🔶 | 不再抽 keywords；模型对照参考答案判分（`check`），更适合小模型 |
| 连续错两次给提示/跳过/归档 | ✅ | `answer wrong|skip` 自动进错题本并计数；`quiz` 错题优先重考 |
| 难度评分与按掌握状态抽题 | 🔶 | 抽题顺序：待复习错题 → 没做过的 → 做过的；无难度分 |
| 范围限定（只考某章/某来源） | ✅ | `quiz --chapter N` / `--all` |
| `verified` 与 `covered_unverified` 区分 | ✅ | `done` 时按本章是否答对过材料题标 `verified` / `done` |

## 结论

学生可见的核心承诺（按资料讲、先看图、只出材料题、记进度、诚实标注）在 v5.1 全部可用，且图片能力比 v4.3 更实在：v4.3 要求智能体自己渲染页面并写回执，v5.1 由脚本裁好图并给出路径。
未实现的四项（画图题先算后画、知识点窗口、Study Guide HTML/PDF、六题型全套）中，前一项可用一句 SKILL 规则补上，其余三项是有意删除的重型功能。
