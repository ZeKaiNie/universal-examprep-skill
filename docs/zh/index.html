把课程文件夹交给编程智能体：它按你的课件讲课并标出处页码，把讲义里的图放到你面前，用你自己的作业和往年卷考你，还记得你学到哪。

适用于 Claude Code、Codex、Cursor、Windsurf、Antigravity、Gemini CLI、GitHub Copilot 等能运行命令的智能体。支持 PDF、PPTX、DOCX、Markdown、TXT、HTML，中英双语。

它能做什么

一章一章讲

自动把整门课切成章节，用大白话讲每一段，每个结论都标出处 文件 p.页码。

讲到哪张图就给你看哪张

从讲义页、题目和解答里裁出图，讲解时直接放进对话。

用你的作业和真题考你

hw2.pdf 自动配 hw2solutions.pdf，“Problem 1.3.10” 自动配它的解答，只出资料里的真题。

编的内容绝不冒充资料

🟢 来自资料 · 🟡 AI 补充 · ⚠️ AI 生成答案。资料没讲的，直接说没讲。

换个对话也记得

进度、错题、笔记和按天排好的复习计划都存在本地文件夹里，新对话从上次停下的地方继续。

小巧、离线、安全

13 个文件，不需要 API 密钥，不联网。课件只当数据：里面对 AI 下指令的句子会被标出，绝不照做。

安装

任意智能体

npx skills add ZeKaiNie/universal-examprep-skill

按提示选择你的智能体；加 -g 装给整个用户。

Claude Code 插件

/plugin marketplace add ZeKaiNie/universal-examprep-skill
/plugin install universal-exam-cram-coach@exam-cram-coach

离线安装

到最新发布页下载 universal-exam-cram-coach-flash.zip 和 SHA256SUMS.txt，解压到智能体的技能目录。

然后对智能体说：“用期末极速备考教练。资料在 D:\课程\概率论，三天后考试，我零基础，用中文从第 1 章开始讲。”

常见问题

支持哪些智能体？

任何能运行命令的编程智能体：Claude Code、Codex、Cursor、Windsurf、Antigravity、Gemini CLI、GitHub Copilot 等。

会编造答案吗？

每句话都有来源标签，测验只用你文件里的题；资料没讲到的内容会直接说明。

能把 PDF 里的图给我看吗？

能：准备阶段会从讲义页、题目和解答里裁出图。

会上传我的资料吗？

不会。它离线运行，只往本地的 exam-cram 文件夹写文件。

小模型能用吗？

能，用 Gemini flash-lite、Gemini flash 和 Claude Haiku 实测过。
