# 第一章 线性表

## 1.1 线性表的定义

线性表是由 n（n ≥ 0）个数据元素组成的有限序列，记作 L = (a1, a2, …, an)。n = 0 时称为空表。
每个元素有且仅有一个直接前驱和一个直接后继（首元素无前驱，尾元素无后继）。

## 1.2 顺序表

顺序表用一段连续的存储单元依次存放线性表的元素，逻辑上相邻的元素物理上也相邻。

- 按位序访问第 i 个元素：O(1)，因为地址 = 基地址 + (i − 1) × 元素大小。
- 在第 i 个位置插入元素：需要把第 i 到第 n 个元素整体后移一位，平均移动 n/2 个元素，时间 O(n)。
- 删除第 i 个元素：需要把第 i+1 到第 n 个元素前移一位，平均移动 (n − 1)/2 个元素，时间 O(n)。

优点：随机访问快、存储密度高。缺点：插入删除要大量移动元素，且需要预先分配容量。

## 1.3 单链表

单链表用结点存放元素，每个结点包含数据域和指向后继的指针域。带头结点的单链表中，头结点不存数据，便于统一插入删除操作。

- 按位序访问第 i 个元素：从头结点开始逐个后移，O(n)。
- 已知前驱结点 p，在其后插入结点 s：`s->next = p->next; p->next = s;`，O(1)。
- 已知前驱结点 p，删除其后继：`q = p->next; p->next = q->next; free(q);`，O(1)。

注意顺序：插入时必须先让 s 指向 p 的后继，再让 p 指向 s，否则后面的结点会丢失。

## 1.4 顺序表与链表的比较

| 操作 | 顺序表 | 单链表 |
| --- | --- | --- |
| 按位序访问 | O(1) | O(n) |
| 插入/删除（已定位） | O(n) | O(1) |
| 存储密度 | 1 | 小于 1 |

选择原则：频繁按位序查找且长度稳定用顺序表；频繁插入删除、长度变化大用链表。
