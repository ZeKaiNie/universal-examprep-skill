# 第三章 树与二叉树

## 3.1 树的基本概念

树是 n 个结点的有限集合，n = 0 时为空树。非空树有且仅有一个根结点，其余结点分成若干互不相交的子树。
- 结点的度：结点拥有的子树个数。树的度：树中结点的最大度。
- 深度：从根到该结点的层数（根为第 1 层）。高度：从该结点到最深叶子的层数。
- 树中结点数 = 所有结点的度之和 + 1。

## 3.2 二叉树

二叉树每个结点至多有两棵子树，且左右子树有顺序之分。

重要性质：
1. 第 i 层至多有 2^(i−1) 个结点。
2. 深度为 k 的二叉树至多有 2^k − 1 个结点。
3. 叶子结点数 n0 与度为 2 的结点数 n2 满足 n0 = n2 + 1。
4. 具有 n 个结点的完全二叉树深度为 ⌊log2 n⌋ + 1。

满二叉树：每层都满。完全二叉树：只有最后一层可以不满，且缺的结点都在右边。

## 3.3 二叉树的遍历

- 先序遍历：根 → 左 → 右。
- 中序遍历：左 → 根 → 右。
- 后序遍历：左 → 右 → 根。
- 层序遍历：按层从上到下、从左到右，用队列实现。

由先序和中序序列可以唯一确定一棵二叉树：先序的第一个结点是根，在中序中找到根，左边是左子树，右边是右子树，递归处理。
由后序和中序也可以唯一确定，但先序和后序不能。

## 3.4 二叉排序树

二叉排序树（BST）：左子树所有结点的值 < 根 < 右子树所有结点的值。中序遍历得到递增序列。
查找、插入的平均时间 O(log n)，最坏（退化成链表）O(n)。
平衡二叉树（AVL 树）通过旋转保证任一结点左右子树高度差不超过 1，使查找始终为 O(log n)。
