# 第二章 栈和队列

## 2.1 栈

栈是只允许在一端（栈顶）进行插入和删除的线性表，特点是后进先出（LIFO）。

顺序栈用数组和一个栈顶指针 top 实现：
- 初始化：top = −1。
- 入栈：先判断栈是否满（top == MaxSize − 1），再 `top++; data[top] = x;`。
- 出栈：先判断栈是否空（top == −1），再 `x = data[top]; top--;`。

共享栈：两个栈共用一个数组，栈底分别在数组两端，栈顶相向增长，top0 + 1 == top1 时栈满。

## 2.2 栈的应用

1. 括号匹配：遇到左括号入栈，遇到右括号弹出栈顶比较，扫描结束后栈空则匹配成功。
2. 表达式求值：中缀表达式转后缀表达式时，运算符入栈，遇到优先级不高于栈顶的运算符时先弹出栈顶。
3. 递归：函数调用时把返回地址和局部变量压入系统栈，递归深度过大会导致栈溢出。

## 2.3 队列

队列是只允许在一端（队尾）插入、在另一端（队头）删除的线性表，特点是先进先出（FIFO）。

循环队列用数组实现，front 指向队头元素，rear 指向队尾元素的下一个位置：
- 入队：`data[rear] = x; rear = (rear + 1) % MaxSize;`
- 出队：`x = data[front]; front = (front + 1) % MaxSize;`
- 判空：front == rear。
- 判满（牺牲一个单元）：(rear + 1) % MaxSize == front。
- 队列长度：(rear − front + MaxSize) % MaxSize。

## 2.4 栈与队列的对比

栈和队列都是操作受限的线性表。栈只在一端操作，队列在两端操作。
双端队列允许两端都插入和删除；输出受限的双端队列只允许一端删除。
